# Student Score Predictor

A beginner machine learning project that predicts a student's exam score
from the hours studied, using Linear Regression.

## Features
- Trains a Linear Regression model with pandas and scikit-learn
- Evaluates with a train-test split (R² and MAE)
- Takes an exam name plus hours as one total (`10`) or several days (`4 5 6`)
- Plots the regression line and your predicted exams with Matplotlib

## How to run
pip install -r requirements.txt
python score_predictor.py

## Tech stack
Python, pandas, scikit-learn, Matplotlib
